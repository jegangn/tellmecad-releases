# TellMeCAD releases

TellMeCAD is a free 2D CAD app for Windows that opens and saves DWG and DXF files. JP Automate Sdn. Bhd. makes it.

Download TellMeCAD from [tellmecad.com/download](https://tellmecad.com/download).

This repository holds only the release files. The update check in TellMeCAD reads them. Each release lists its files in `SHA256SUMS.txt`.

For help, email [support@tellmecad.com](mailto:support@tellmecad.com).
